# zumir: Native Code from R Without a Compiler, with 'MIR'

Brings 'MIR', a lightweight just-in-time compiler, to R. Other packages
link to it through a versioned C interface to build functions and get
native code back, or 'MIR' interpreter code where no code generator
exists for the processor. R users can compile a short numeric C
function, or a numeric R function in a documented subset of the
language, to native code from R, with no system compiler installed.
